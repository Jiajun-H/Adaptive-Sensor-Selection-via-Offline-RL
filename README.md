# Adaptive Sensor Selection for Resource-Constrained Compartmental Fire Early Warning via Offline Reinforcement Learning

This repository contains Python scripts for offline reinforcement learning based adaptive sensor selection for compartmental fire early warning, including data preparation, training, evaluation, inference, and visualization. Install dependencies from `environment.yml` or `requirements.txt`, and run scripts from the repository root.

Experimental Excel workbooks, the DOCX document, model checkpoints, and generated figures are not included. Put multi-experiment workbooks in `converted_excel/` or provide `data.xlsx` for the legacy single-workbook mode.
